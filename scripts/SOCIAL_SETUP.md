# X（旧Twitter）運用：完全無料・手動投稿

## 背景
X API は**無料の投稿枠が廃止**され、従量課金（投稿1回 $0.015、URL付きは $0.200）になりました。
そのため**API経由の自動投稿はやめ、無料の手動運用**にしています。
※**手動でX画面から投稿する分にはURL付きでも無料**です（課金されるのはAPI投稿のみ）。

## 運用フロー（おすすめ：週1回まとめて予約）

### 1. 投稿文をまとめて生成
```bash
node scripts/daily-question.mjs --backlog 21
```
- DBの本物の過去問から「メイン投稿＋正解リプ」を21本（≒1週間×1日3回分）生成します。
- 図表問題は自動除外、280字超は選択肢省略版を自動提案、出典(IPA)＋アプリURL＋ハッシュタグ付き。
- 出した問題を「投稿済み」にして次回から除外したい場合は末尾に `--mark` を付ける：
  ```bash
  node scripts/daily-question.mjs --backlog 21 --mark
  ```

### 2. Xの「予約投稿」で朝・昼・夕にセット（無料）
1. X（ブラウザ版）で投稿作成画面を開く
2. 生成した「メイン投稿」を貼り付け
3. 投稿ボタン横の**カレンダー（予約）アイコン**で日時を指定（例：7:30 / 12:30 / 18:30）
4. 「正解リプ」は、メイン投稿後にスレッドへのリプとして同様に投稿（または手動でぶら下げ）
5. 1週間分まとめて予約しておけば、あとは自動で流れます

### 3. 固定ツイート＆プロフィール
- アプリURLは**プロフィールのウェブサイト欄**と**固定ツイート**にも置いてあるので、
  ツイート本文のURLが無くても誘導できます。
